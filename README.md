# Car Price Prediction with Machine Learning

## Project Overview
This project predicts car selling prices using machine learning regression techniques. The analysis uses car features such as year, present price, kilometers driven, fuel type, seller type, transmission, and ownership.

## Dataset
The dataset contains 301 car records with the following features:
- Car Name
- Year
- Selling Price
- Present Price
- Kilometers Driven
- Fuel Type
- Seller Type
- Transmission
- Owner

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Machine Learning
Regression models were used to predict car selling prices.

Models:
- Linear Regression
- Random Forest Regression

## Methodology
1. Loaded the dataset
2. Explored the dataset
3. Checked missing values
4. Checked duplicate records
5. Performed feature engineering
6. Visualized relationships between car features and selling price
7. Encoded categorical variables
8. Split the dataset into training and testing sets
9. Trained regression models
10. Evaluated model performance
11. Compared actual and predicted prices
12. Predicted the price of a new car

## Conclusion
The project demonstrates how machine learning can be used to predict car prices based on different vehicle characteristics. The analysis helps understand the factors that influence car selling prices and shows a practical application of regression in machine learning.
